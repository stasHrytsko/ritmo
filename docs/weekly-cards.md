# Карточки недели — банк идей

Статус: рабочий документ, постоянно пополняется.
Механика (появление, дедлайн, ачивки по сложности) описана в
`docs/v3-game-layer.md` — здесь только содержимое самих карточек.

## Правила для авторов карточки

- Одна карточка = одно направление + одна конкретная формулировка,
  без вариантов внутри самой карточки.
- Тон: неожиданно, приятно, интересно, немного волнительно, не сложно
  физически или организационно.
- Сложность (лёгкая/средняя/сложная) — это про решимость, масштаб и
  социальный риск, а не про трудозатратность или время.
- Карточка никогда не про рутины и не про эффективность — она ведёт в
  жизнь, а не в очередной чек-лист.
- Формулировка — сегодня/на этой неделе, без «попробуй когда-нибудь».

## Направления

Из чего собираются карточки:

- сделать что-то своими руками
- сходить куда-то новое
- попробовать то, чего раньше не делал
- подарить/сделать что-то для другого человека без повода
- сделать привычное иначе, чем всегда

## Референсы (по духу, не конкуренты)

- Alastair Humphreys, *Microadventures: Local Discoveries for Great
  Escapes* — книга про маленькие дешёвые приключения рядом с домом;
  свои истории + how-to часть.
- Declutter Deck / Ten Minute Tidying Tasks (Hack Decks) — формат
  «вытянул карточку — сделал бытовую задачу на таймер».
- Deckible — площадка приложений именно жанра «ежедневный/недельный
  вызов по карточке».
- Ни один из них не встроен в полноценный трекер рутин/целей — везде
  либо только быт/уборка, либо генератор карточек сам по себе.

## Готовые карточки

### Лёгкие

- **Другая дорога** — Сегодня пройди привычный путь — домой, до
  работы, до магазина — не так, как всегда. Сверни не туда, куда
  обычно.

### Средние

- **Сделано руками** — На этой неделе сделай своими руками вещь,
  которую обычно покупаешь готовой. Блюдо с нуля, открытка, полка —
  что угодно, лишь бы не куплено.

### Сложные

- **Без повода** — Выбери человека и на этой неделе сделай для него
  что-то без всякого повода — подарок, письмо от руки, просто час
  времени, который назначил не календарь, а ты сам.

## Черновик — новые идеи (не рассортированы по сложности)

- **Секретный получатель** — оставь что-то приятное для случайного
  человека так, чтобы не увидеть его реакцию.
- **Час без экрана в новом месте** — проведи час там, где не был,
  без телефона.
- **Готовка вслепую** — приготовь блюдо кухни, которую никогда не
  готовил.
- **Разговор, который откладывал** — позвони человеку, с которым
  давно не говорил, без повода.
- **Письмо в будущее** — напиши письмо себе через год и отложи его
  так, чтобы точно найти через год.
