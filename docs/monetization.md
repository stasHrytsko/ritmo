# Монетизация: подписка vs разовая косметика

Статус: расчёт для решения, ничего не реализовано.
Принцип (ядро и вся игра бесплатны всегда, платится только внешность/
сервис) — см. `docs/v3-game-layer.md`. Список конкретных платных вещей
(скины медалей, тема, скин карты, облачный синк, экспорт года) — из
обсуждения в чате, сюда пока не выносился отдельным списком.

## Что сравниваем

- **Модель A — подписка.** Как у Finch Plus и Habitica: разовый
  ежемесячный/годовой платёж открывает доступ ко всей библиотеке
  косметики (скины медалей, темы, скины карт) сразу и ко всему новому,
  что добавляется дальше. Механика по-прежнему бесплатна для всех —
  подписка не даёт игрового преимущества, только внешний вид.
- **Модель B — разовая косметика.** Каждый скин продаётся отдельно,
  один раз, без подписки. Купил — владеешь всегда.

## Источники цифр

- RevenueCat, *State of Subscription Apps 2026*: медианная конверсия
  download → paid на 35-й день для приложений **без хард-пейвола**
  (freemium, ровно наш случай — без обязательного триала) — **2.1%**.
  Хард-пейвол даёт 10.7%, но это не наш путь: Ritmo никого не заставляет
  платить, чтобы попробовать.
- Тот же отчёт: конверсия триал → платёж у Health & Fitness (39.9%
  медиана) — это **другая ступень воронки** (уже начавшие триал), не
  сравнима напрямую с «сколько из всех пользователей вообще заплатят»,
  поэтому в расчёт не берём.
- Общий бенчмарк по разовым (не подписочным) покупкам в приложениях:
  типично **1–5%** конверсии, **7%+** — сильный результат. Отраслевого
  бенчмарка именно для косметики в трекерах привычек не нашлось — это
  общий показатель по всем разовым IAP.
- Habitica: подписка $4.99/мес или $47.99/год, косметика без
  преимущества в механике.
- Finch: Finch Plus $9.99/мес или $69.99/год, тоже только косметика;
  при ~400k загрузок/мес — около $2M выручки/мес (это уже не 1000
  пользователей, а ориентир, что модель вообще работает в масштабе).

## Расчёт на 1000 пользователей

Не измеренные, а принятые для расчёта допущения помечены отдельно.

### Модель A — подписка

| | |
|---|---|
| Конверсия (источник: RevenueCat, freemium D35) | 2.1% |
| Платящих из 1000 | ≈ 21 |
| Цена (допущение — уровень Habitica, не Finch) | $47.99/год |
| Выручка за год (без учёта оттока подписчиков в течение года) | ≈ **$1 000** |

### Модель B — разовая косметика

| | |
|---|---|
| Конверсия (источник: общий бенчмарк non-subscription IAP, взята середина диапазона) | 3% |
| Платящих из 1000 | ≈ 30 |
| Средний чек за год на платящего (**допущение**: обычно берут не один скин, а 2–3 за первый год по ~$3) | ≈ $7.5 |
| Выручка за год | ≈ **$225** |

### Итог

Подписка даёт примерно в **4–5 раз больше** выручки при том же
количестве пользователей — не потому что платит больше людей (у
косметики конверсия даже выше), а потому что каждый платящий приносит
намного больше денег за счёт регулярности платежа.

На 1000 пользователей в абсолютных цифрах разница некритична — речь про
несколько сотен долларов в год в любом случае. Смысл сравнения не «на
чём заработать сейчас», а какая модель лучше масштабируется: при росте
до 50–500 тысяч пользователей разрыв между двумя моделями растёт в тех
же пропорциях, и там разница уже ощутима.

## Важная оговорка

Подписка «плати за косметику» работает только если библиотеку скинов
реально пополнять — Finch и Habitica держат подписчиков не одним
набором картинок, а постоянным потоком нового. Без этого отток
подписчиков быстро съест разницу с моделью B. Это не разовая
инженерная задача, а обязательство продолжать выпускать контент.

Не делать: контент только «этот месяц для подписчиков» (так у
Habitica) — это давление через упущенную выгоду, а не честная
косметика. Всё новое должно оставаться в каталоге навсегда.

## Практический вывод

- Основная модель — подписка на косметику (как Finch/Habitica).
- Рядом можно оставить разовую покупку отдельных скинов — как
  дополнение для тех, кто не готов подписываться, а не вместо
  подписки. Finch делает и то, и другое одновременно.
- Начинать строить платёжную инфраструктуру раньше, чем заработает и
  приживётся сама бесплатная игровая механика (карта недели, медали),
  преждевременно — см. критерий готовности в `docs/v3-game-layer.md`.
