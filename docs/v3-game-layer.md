# Ritmo V3 — игровой слой: карта недели и награды

Статус: утверждено в обсуждении, ничего не реализовано в коде.
Дополняет исходный документ «Ritmo — MVP V3» (Google Docs). Часть решений
ниже заменяет разделы того документа — см. «Что отменяет этот документ»
в конце.

## Принцип монетизации

- Основной трекер (Сегодня/Прогресс/Жизнь/Заметки) бесплатен всегда, без
  исключений.
- Весь игровой слой ниже — карта недели, ачивки, медали — тоже полностью
  бесплатен и зарабатывается только использованием приложения.
- Если позже появится монетизация — это только альтернативный визуальный
  вид уже заработанных вещей (скин медали, палитра). Никогда: реролл
  карты за деньги, покупка ачивки, что-либо дающее преимущество.
- Ориентир по модели — Finch (Finch Plus: только косметика, ядро бесплатно
  без рекламы) и Habitica (подписка даёт только внешний вид, не механику).

## Карта недели (Weekly Card)

Отдельная от рутин механика: не про выполнение привычек, а про
разнообразие — доброволное, неожиданное, не сложное задание раз в неделю.

**Появление.** Каждый понедельник — новый набор из 3 карт, закрытых
(рубашкой вверх). В приложении появляется тихо (бейдж/иконка), без пуша.
Пуш можно включить в настройках, по умолчанию выключен.

**Выбор.** Всегда ровно 3 карты: одна лёгкая, одна средняя, одна сложная.
Пользователь выбирает 1 вслепую, не зная содержимого — это осознанно
оставленный элемент неожиданности (формально похоже на mystery box, но без
доната за дополнительные попытки/реролл — это и есть граница, которая не
даёт механике стать манипулятивной).

**Содержание.** После выбора карта открывается и показывает одно
задание на неделю, не связанное с рутинами. Примеры направлений:
- сделать что-то новыми руками
- подарить кому-то что-то
- сходить в новое место
- попробовать что-то, чего раньше не делал
- ускорить/сжать что-то привычное иначе, чем обычно

Тон задания: неожиданно, приятно, интересно, немного волнительно, не
сложно физически или организационно (сложность карты — про решимость и
масштаб, не про трудозатратность).

**Срок.** Дедлайн всегда до конца текущей календарной недели, независимо
от того, в какой день недели карта была открыта (открыл в среду — закрыть
нужно до воскресенья). Привязано к тому же недельному циклу, что и вся
остальная логика приложения.

**Если не открыл.** Набор карт просто сгорает в конце недели без
последствий. В следующий понедельник — новый набор из 3 карт. Никакого
штрафа, ничего не прерывается.

**Награда.** Выполненная карта не даёт медаль недели и не входит в расчёт
процента выполнения рутин — это полностью отдельная линия. Она пополняет
счётчик по сложности (см. ниже).

## Ачивки по картам

Три отдельных счётчика за всё время пользования:
- закрыто лёгких карт — X
- закрыто средних карт — X
- закрыто сложных карт — X

Все три карты в наборе дают одинаковую награду при закрытии (плюс к
своему счётчику) — сложность карты не даёт более ценный приз, только
собственный счётчик. Пороги/уровни внутри этих счётчиков (например,
бронза/серебро/золото за 5/25/100 закрытых сложных карт) — не определены,
открытый вопрос.

## Медали: золото / серебро / бронза

Единая система, применяется на четырёх масштабах одинаково: день, неделя,
месяц, год.

- Золото — 100% запланированного выполнено
- Серебро — от 70% до 99%
- Бронза — от 50% до 69%
- Меньше 50% — без медали, без штрафа, просто ничего
- Если на этот период не было запланировано ни одной задачи (0 из 0) —
  период пропускается целиком, без медали, не засчитывается ни в плюс,
  ни в минус

Считается по той же величине, что уже показывается в Прогрессе
(доля выполненных из запланированных рутин за период) — отдельного
движка подсчёта не нужно, только пороги поверх существующего процента.

Независимо от карты недели — свою собственную линию наград карта недели
не трогает.

## Серия (streak)

Отдельная «серия дней подряд» (текущий флейм-чип в шапке) — убирается из
игрового слоя. Роль «сигнала стабильности» теперь выполняют сами медали
на четырёх масштабах (особенно неделя/месяц/год) — они по конструкции не
могут «сломаться» так, как рвётся серия, каждый период оценивается сам по
себе.

Открытый вопрос: убрать ли существующий флейм-чип из интерфейса или
оставить его как отдельную самостоятельную вещь, не связанную с этой
системой наград — не решено.

## Анимация закрытия

Праздничная анимация (конфетти) — только на золоте, на любом из четырёх
масштабов. Серебро и бронза отражаются только визуально (цвет/вид медали),
без салюта — чтобы момент золота не терялся.

## Где смотреть награды

- Быстрый взгляд — один тап с экрана Сегодня (точное место элемента
  зависит от того, что займёт место флейм-чипа — открытый вопрос выше)
- Полная картина — экран Прогресс → Год: туда естественно ложится блок
  с медалями по масштабам и ачивками по картам, без новой вкладки в
  навигации

## Открытые вопросы

- Чем заменить флейм-чип на Сегодня, раз серия уходит из игрового слоя
- Пороги/уровни внутри счётчиков по сложности карт
- Реальный пул текстов карт (сейчас есть только примеры направлений)
- Пересчитываются ли месяц/год «вживую» по ходу периода или фиксируются
  только при его закрытии
- Судьба текущей реализации серии в коде — трогать её сейчас не нужно

## Что отменяет этот документ

Относительно исходного «Ritmo — MVP V3»:
- Boons (буны, меняющие способ выполнения рутин) — заменены на карту
  недели с заданием, не связанным с рутинами.
- Развёрнутый список Relics и множественных типов медалей из черновых
  набросков — заменён на единую систему золото/серебро/бронза по
  проценту + отдельные ачивки по сложности карт.
- Draft-понедельник как блокирующий/обязательный ритуал — карта недели
  явно необязательна и не блокирует использование приложения, дух
  исходного документа тут сохранён.

Остальное из исходного документа (принцип «нет валюты/магазина/лутбоксов
за деньги», иммутабельность истории, отсутствие пуш-давления по
умолчанию) остаётся в силе и уточняется, а не отменяется.
